# priv/data/ -- Technique Data Files

> Parent: [apps/prismatic_annihilation/](../../README.md)

---

## Overview

Runtime data files containing the complete Epistemic Annihilation Compendium in structured JSON format. Generated by the Compendium Pipeline from Czech markdown sources in the Garden ecosystem.

**Total**: 178 technique definitions, 65 detection pattern files, 6 schemas, 4 relationship graphs, plus supporting indexes and translations.

---

## Directory Structure

```
priv/data/
|-- technique_index.json          # Master index of all 178 techniques
|-- translations_cs_en.json       # Czech-to-English name translations
|-- cognitive_biases.json         # Cognitive bias reference data
|-- deception_patterns.json       # Deception pattern reference data
|-- manipulation_techniques.json  # Manipulation technique reference data
|-- taxonomy/                     # 178 individual technique JSON files
|   +-- README.md
|-- patterns/                     # 65 detection rule files
|   +-- README.md
|-- schemas/                      # 6 JSON Schema validation files
|   +-- README.md
+-- relationships/                # 4 cross-reference and relationship graphs
    +-- README.md
```

---

## Key Files

### technique_index.json

Master index containing technique IDs, names, categories, and severity levels for all 178 techniques. Used by the `TaxonomyServer` for fast loading and initial population of indexes.

### translations_cs_en.json

Bilingual name mapping (Czech original to English translation) for all technique names. Used by `TaxonomyServer.translate/1`.

### Reference Data

| File | Contents | Usage |
|------|----------|-------|
| `cognitive_biases.json` | Catalogued cognitive biases | Cross-reference with detection |
| `deception_patterns.json` | Deception technique patterns | EvilBridge correlation |
| `manipulation_techniques.json` | Manipulation method definitions | EvilBridge correlation |

---

## Data Generation

All data in this directory is generated by the Compendium Pipeline:

```bash
# Regenerate all data from Garden sources
mix compendium.extract

# Validate existing data
mix compendium.extract --validate
```

See the [Compendium Pipeline documentation](../../lib/prismatic_annihilation/compendium/README.md) for details.

---

## Data Loading at Runtime

```
Application Start
    |
    +-- CompendiumLoader loads priv/data/*.json
    |
    +-- TaxonomyServer loads priv/data/taxonomy/*.json
    |       +-- Builds by_category, by_severity, by_subcategory indexes
    |       +-- Loads translations from translations_cs_en.json
    |
    +-- PatternCompiler may load priv/data/patterns/*.json
```
