# priv/data/patterns/ -- Detection Rule Files

> Parent: [priv/data/](../README.md) | Project: [apps/prismatic_annihilation/](../../../README.md)

---

## Overview

Contains **65 JSON detection rule files** that define pattern-matching rules for identifying epistemic annihilation techniques in content. These files complement the Elixir-native pattern modules in `lib/prismatic_annihilation/patterns/`.

Additionally contains `_all_detection_patterns.json`, a consolidated index of all patterns across all files.

## File Format

Each detection rule file contains pattern definitions organized by category:

```json
{
  "category": "epistemic_destruction",
  "description": "Detection patterns for epistemic destruction techniques",
  "patterns": [
    {
      "id": "ed_implosion_01",
      "name": "Epistemic Implosion Detection",
      "technique_references": ["EA-105-epistemicka-imploze"],
      "keywords": [
        "epistemic implosion",
        "cognitive singularity",
        "knowledge collapse",
        "gravitational knowledge pull"
      ],
      "regex_patterns": [
        "epistemic.*(?:collapse|implo)",
        "knowledge.*singularity"
      ],
      "severity": "critical",
      "confidence_weight": 0.85,
      "indicators": [
        "Self-referential knowledge destruction",
        "Cognitive compression beyond recovery"
      ]
    }
  ],
  "metadata": {
    "generated_at": "2025-01-15T10:30:00Z",
    "pattern_count": 12
  }
}
```

## Relationship to Elixir Modules

```
JSON Pattern Files (priv/data/patterns/)     Elixir Pattern Modules (lib/.../patterns/)
+-----------------------------------+        +-----------------------------------+
| 65 JSON files                     |        | GravitationalPatterns             |
| - Loaded by CompendiumLoader      |        | InfectionPatterns                 |
| - Used for extended matching      |        | ParadoxPatterns                   |
| - Generated by Pipeline           |        | CollapsePatterns                  |
+-----------------------------------+        | - Compiled Elixir code            |
                                             | - High-performance matching       |
                                             | - ETS-indexed by PatternCompiler  |
                                             +-----------------------------------+
```

Both sources contribute to the detection engine. The Elixir modules provide compiled, high-performance matching while the JSON files enable data-driven pattern updates without code changes.
