# Případové studie

> **Etická poznámka**: Všech 60 kazuistik publikovaných v této sekci je **plně anonymizovaných**. Identifikační znaky byly modifikovány, časové a lokační referenty rozkmitány, a v některých případech jsou jednotlivé kazuistiky **syntetickými kompozicemi** z multiplicitních srovnatelných případů. Účelem této sekce je **edukativní mapování fenomenologie EA-technik** napříč doménami — nikoli rekonstrukce konkrétních subjektů ani provozní návod. Některé kazuistiky byly publikovány se souhlasem klientů po terapeutickém uzavření a víceletém odstupu.

## Účel sekce

Sekce **Případové studie** poskytuje **600+ stran kazuistického materiálu** organizovaného do 60 anonymizovaných případů, které jsou **systematicky mapovány na taxonomii EA-technik** ([viz sekce techniques](/kompendium/techniques/)) a klinické rámce ([sekce 06](/kompendium/06-klinicke-aplikace/)). Každá kazuistika obsahuje:

- **Kontextovou anamnézu** — anonymizované demografické a situační údaje
- **Časovou linii expozice** — chronologie postupné destabilizace (typicky 18 měsíců až 12 let)
- **Mapování EA-technik** — explicitní kódy `EA-X.Y.Z` s cross-linky do taxonomie
- **Fenomenologický průběh** — pětifázová progrese (iniciace → afilace → kapitulace → destabilizace → eventuální detekce/rekonstrukce)
- **Detekční bod** — moment, ve kterém byl případ identifikován (klinicky, supervizorsky, rodinou, externě)
- **Intervenční strategii** — aplikovanou terapeutickou nebo institucionální odpověď
- **Výsledek** — trajektorie zotavení (plná remise, parciální remise, relaps, neukončené)
- **Cross-linky** na relevantní kapitoly kompendia a glosáře

## Struktura kazuistiky

Každá kazuistika dodržuje konzistentní strukturu (~700–1000 slov) zahrnující:

| Pole | Účel |
|------|------|
| **Kód případu** | Anonymizovaný identifikátor (např. `K-NN-DOMAIN`) |
| **Doména** | Kontextová třída (akademie, rodina, kult, korporát, online) |
| **Trvání expozice** | Časový rozsah destabilizační fáze |
| **Trvání terapie** | Délka rekonstrukční trajektorie |
| **Manifestované techniky** | Explicitní seznam `EA-X.Y.Z` kódů |
| **Kompoziční vzorec** | Rozpoznaný strukturální vzorec (Guru/adept, Mob, Echo chamber, Dyad) |
| **Komorbidity** | Souběžná psychopatologie (úzkost, deprese, derealizace, PTSD) |
| **Výsledek** | Funkční status v dvouletém follow-up |

## Defenzivní rámec

Tato sekce je publikována v **defenzivním rámci** — slouží:

1. **Klinickému rozpoznávání** — etablování fenomenologických šablon pro diagnostické rozhodování
2. **Edukaci pro postižené** — možnost rozpoznat vlastní expozici v anonymních zrcadlech
3. **Edukaci pro odborníky** — supervizorům, terapeutům, akademikům, lidskoprávním pracovníkům
4. **Etablování taxonomie** — empirickému zpevnění mapování technik na klinické fenomény

**Sekce není provozním návodem.** Všechny popisy technik jsou strukturní (co se dělo), nikoli implementační (jak to udělat). Rozdíl mezi **detekční gramotností** a **operacionální exploatací** je v této sekci striktně udržován ([viz dual-use poznání](/glossary/dual-use-poznani/)).
