# Bridge — violation-protocol

**Z kompendia → do glossary**: tento bridge článek navigačně propojuje kompendium s odpovídajícím glossary heslem a poskytuje rozšířený interpretační kontext propojení.

## Definice z glossary

[violation-protocol](@/glossary/violation-protocol.md) — Violation protocol je formální procedura pro rozpoznání, dokumentaci a remediaci porušení platformové doktríny. Definuje sérii kroků: detekce, klasifikace závažnosti, root cause analysis, remediation plán, post-mortem a aktualizace prevence pro budoucnost.

Glossary entry slouží jako kanonický referenční bod platformy; bridge článek rozšiřuje stručnou definici o platformový a interpretační kontext, v němž koncept skutečně operuje.

## Pozice v kompendiu

Tento koncept se vyskytuje napříč kompendiem v následujících kontextech:

- **Sekce 08 — Doctrina**: violation protocol jako enforcement layer
- **Per-technique: Post-mortem Workflow**: non-blameful root cause analysis
- **Sekce 09 — Pre-commit Hooks**: preventivní vrstva před violation
- **Sekce 10 — Audit Trail**: evidence porušení a remediace

Každý z těchto výskytů přidává specifickou perspektivu — operativní pipeline, teoretické pozadí, klinickou aplikaci nebo metodologickou reflexi.

## Konceptuální mapa

| Subjekt | Vztah | Objekt |

| **Violation protocol** | definuje | Detekci → klasifikaci → root cause → remediaci → post-mortem |
| **Violation protocol** | vyžaduje | Non-blameful kulturu pro otevřenou root-cause analýzu |
| **Violation protocol** | produkuje | Aktualizovanou prevenci pro budoucnost |

## Platformové implikace

Hodnota protokolu závisí na non-blameful kultuře — protokol, který trestá osoby místo zlepšování systému, vede ke skrývání porušení a degraduje data o reálných selháních. Disciplinovaná organizace odděluje akontabilitu (osoba se k porušení přihlásí) od trestu (systém se zlepší), a tím transformuje violation z stigmatu na příležitost k učení.
