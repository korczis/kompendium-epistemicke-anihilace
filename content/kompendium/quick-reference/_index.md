# Quick Reference — rychlé karty

Komplementární vrstva k hloubkovým článkům. Pro každou klíčovou jednotku kompendia (EA technika, klinický nástroj, filosofický koncept) existuje **1-stránková referenční karta** s:

- EA kód / název
- 1-věta definice
- 3-bodový operační modus
- 3 detekční markery
- 3 neutralizační strategie
- Cross-linky na detailní článek + glossary + související

## Účel

- **Klinická pohotovost** — rychlé připomenutí během konzultace
- **Studijní přehled** — kompaktní review pro examination
- **Forensní práce** — rychlé porovnání případů s katalogem
- **Edukativní handout** — printovatelný list pro tréninky

## Karty

Každá karta sleduje uniformní strukturu. Celkem 100+ karet pokrývajících:

- **EA-1.X.Y techniky** (13 karet)
- **EA-2.X.Y delegitimizace** (50 karet)
- **EA-5.1.* singularita** (30 karet)
- **EA-5.2.* metatranscendentální** (10 karet)
- **Klinické nástroje** (15 karet)
- **Filosofické koncepty** (15 karet)
