# Bridge: Visualizations → Techniques

> **Z:** Visualizations → **Do:** Techniques
> **Typ:** Inter-section bridge (sekce-na-sekci)
> **Reciprocita:** Bidirektionální navigace mezi sekcemi.

## 1. Účel bridge

Visualizations bez Techniques jsou **estetické artefakty**; Techniques bez Visualizations jsou **kognitivně náročné stěny textu**. Bridge ukazuje, jak vizualizace vede čtenáře zpět k technice — vizualizace má vždy referenci, která ji vysvětluje.

## 2. Klíčová témata propojení

- **Diagram → text techniky.**
- **Decision tree → rozhodovací technika.**
- **State machine → stavová technika.**
- **Network graph → síťová technika.**
- **Heatmap → distribuční technika.**
- **Animation → dynamická technika.**
- **Vizualizace jako kognitivní lešení.**

## 3. Doporučená čtenářská trajektorie

Vizualizaci si přečtěte VŽDY s odkazem na technické vysvětlení. Vizualizace se nikdy nečte samostatně bez doprovodného textu. Pořadí: vizualizace → text → vizualizace → text.

## 4. Společné cross-linky

| Z Visualizations | Do Techniques |
|---|---|
| Diagram A | Technika A |
| Decision tree B | Technika B |
| State machine C | Technika C |
| Network graph D | Technika D |

## 5. Specifické techniky / koncepty

Klíčové koncepty: **kognitivní lešení**, **vizualizace jako reference**, **text jako definiční páteř**, **vizualizační konzistence**.

## 7. Meta-poznámka: vizualizace jako epistemický akt

Vizualizace v EA kompendiu nejsou ilustrace — jsou **epistemické akty**, které rozhodují, co je vidět a co je skryto. Decision tree zvýrazňuje větvení a marginalizuje uzlový obsah. Network graph zvýrazňuje vztahy a marginalizuje atributy. State machine zvýrazňuje přechody a marginalizuje obsah stavu. Bridge upozorňuje, že **každá vizualizace má svou ztrátu** — to, co diagram zjednodušuje, technický text musí kompenzovat. Praktické pravidlo: pokud vizualizace neodkazuje zpět na text, je to estetika; pokud text neodkazuje na vizualizaci, je to akademická hustota. Funguje pouze recipročně. NCLB doctrine vyžaduje, aby každý vizualizační artefakt měl evidence-link na zdrojovou techniku.

## 8. Vizualizační konzistence napříč kompendiem

Bridge zdůrazňuje **vizualizační konzistenci**: stejný typ techniky má vždy stejný typ vizualizace napříč kompendiem. Decision tree má vždy stejný styl, state machine vždy stejnou notaci, network graph vždy stejnou layout. Tato konzistence je vynucována v platform Visualizations engine a auditována pre-commit hookem. Bez konzistence by čtenář musel pro každou vizualizaci znovu osvojovat notaci.
